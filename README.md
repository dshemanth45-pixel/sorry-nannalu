# A Letter in Bloom (A Letter I Owe You)

A romantic, luxury editorial apology website crafted with Next.js, Tailwind CSS, GSAP, Framer Motion, and Lenis smooth scrolling.

## Features
- **Editorial Typography**: Cormorant Garamond, Plus Jakarta Sans, and Alex Brush calligraphy
- **Interactive Experience**: Hero letter reveals, quote cards, timeline progression, and forgiveness feedback
- **Smooth Physics**: Lenis smooth scroll and GSAP scroll-driven animations
- **Fully Responsive**: Optimized for mobile phones, tablets, and desktop screens

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the site.
